# Expense-Tracker

A simple expense tracker built using HTML, CSS, and JavaScript.  
It allows users to record expenses and understand their spending by category.

## Features

- Add an expense with its name, amount, and category
- View category totals
- Search transactions by name
- Filter transactions by category
- Sort transactions by amount
- Switch between light and dark mode
- Save transactions in the browser
- Responsive design for smaller screens

## Technologies Used

- HTML
- CSS
- JavaScript
- Font Awesome
- Browser local storage

## What I Learned

While building this project, I practised DOM manipulation, arrays, local storage, form validation and learnt searching, filtering, sorting, responsive CSS, and dark mode.
